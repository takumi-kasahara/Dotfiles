# Dotfiles

This repository is a collection of personal dotfiles and environment configurations for Windows and Linux.

## Usage

1. Clone this repository.
2. Check the configuration files in each folder and apply them as needed for your environment.
3. Review the contents of any `Install.*` scripts or registry files before running, as they depend on your local environment.

## Notes

- This is a dotfiles repository and does not provide an application build or runtime environment.
- It is recommended to back up your original files before changing any environment-specific settings.
